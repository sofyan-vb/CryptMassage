# 🔐 ChronoCrypt - Secure Message Cipher (Deep Obsidian & Emerald Mint)

A modern, minimalist web application for reversible **1:1 proportional text encryption and decryption** with zero expiration or validity timeouts.

---

## 🚀 Key Features

1. **Dual Dedicated Workflows (Encrypt & Decrypt)**:
   - **Encrypt Tab**: Enter original text $\rightarrow$ click *Encrypt Message* $\rightarrow$ instantly produces balanced, reversible scrambled text $\rightarrow$ *Copy* & *Send to Decrypt* buttons.
   - **Decrypt Tab**: Paste cipher text $\rightarrow$ click *Decrypt Message* $\rightarrow$ accurately restores original text.

2. **1:1 Proportional Character Length**:
   - Encrypted output preserves the length and spacing of your original message.
   - No bloated Base64 blocks or messy multi-line hashes.

3. **Permanent & Self-Contained (No Expiration)**:
   - No validity limits or countdown resets. Messages can be encrypted and decrypted anytime.
   - Built-in verification checksum ensures cipher integrity.

4. **Privacy Blur (Anti-Peeking)**:
   - One-click blur mode hides decrypted messages from curious eyes and over-the-shoulder peeking.

5. **Aesthetic & Minimalist UI**:
   - Deep obsidian dark theme (`#090c12`) with emerald mint accents (`#10b981`).
   - Clean, lightweight SVG vector icons without emoji clutter.
